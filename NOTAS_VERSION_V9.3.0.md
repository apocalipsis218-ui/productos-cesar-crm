# V9.3.0 — Mobile First

## Cambios principales

- Navegación inferior de cinco accesos con menú **Más**.
- Encabezado móvil compacto y fijo.
- Botones visualmente resumidos, conservando una zona táctil segura.
- Tarjetas, KPI, paneles, formularios y filtros con menor densidad.
- Modales como hojas inferiores para uso con una mano.
- Kanban móvil por pestañas de etapa en lugar de ocho columnas horizontales.
- Reportes con dos KPI por fila y filtros compactos.
- Órdenes, carnicería, validación y liquidación optimizadas para pantalla estrecha.
- Compatibilidad con áreas seguras de Android/iPhone.
- Escritorio y tablet conservan la interfaz completa.

## Alcance

Esta versión mejora la interfaz móvil. La instalación como PWA se realizará en la V9.3.1.
