# Productos César CRM · V9.3.2

## Barra lateral plegable

- Botón en el separador izquierdo para ocultar o mostrar el menú.
- El contenido principal usa todo el ancho cuando el menú está oculto.
- La preferencia se guarda localmente en cada computadora o tablet.
- La navegación móvil inferior no cambia.
- No requiere SQL ni cambios en Supabase.
