# Aplicar V9.3.0 — Mobile First

1. En GitHub Desktop use **Fetch origin** y **Pull origin**.
2. Detenga Vite con `Ctrl + C`.
3. Copie el contenido del parche dentro de `C:\Proyectos\productos-cesar-crm`.
4. Acepte reemplazar archivos. No elimine `.git` ni `.env.local`.
5. Ejecute:

```powershell
npm.cmd install
npm.cmd test
npm.cmd run dev
```

6. Pruebe en el celular o con el modo responsive del navegador.
7. Commit recomendado: `V9.3.0 - Interfaz Mobile First`.

No requiere SQL ni cambios en Supabase.
