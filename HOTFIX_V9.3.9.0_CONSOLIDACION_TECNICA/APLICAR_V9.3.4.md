# Aplicar V9.3.4

1. Copiar el HOTFIX sobre `C:\proyectos\productos-cesar-crm`.
2. Ejecutar el instalador PowerShell.
3. Confirmar `Auditoría Historiales Compactos V9.3.4 aprobada.`
4. Publicar con `npx.cmd wrangler deploy`.
5. En la PWA, guardar el trabajo abierto y pulsar **Actualizar ahora**.

No requiere SQL nuevo.
