PRODUCTOS CESAR CRM - V9.3.1 PWA

1. Coloque esta carpeta dentro de:
   C:\proyectos\productos-cesar-crm

2. Ejecute desde PowerShell:
   powershell -ExecutionPolicy Bypass -File ".\HOTFIX_V9.3.1_PWA\APLICAR_V931_PWA.ps1"

3. El instalador realiza:
   - respaldo de los archivos que modifica;
   - instalacion de vite-plugin-pwa;
   - npm test;
   - npm run build.

4. Luego pruebe:
   npm.cmd run dev

No requiere SQL ni cambios en Supabase.
