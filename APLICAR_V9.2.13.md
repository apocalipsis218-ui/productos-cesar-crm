# Aplicar V9.2.13 en GitHub

1. Detenga Vite con `Ctrl + C`.
2. Copie el contenido de este parche dentro de `C:\Proyectos\productos-cesar-crm`.
3. Acepte reemplazar los archivos.
4. No borre `.git` ni `.env.local`.
5. Ejecute:

```powershell
npm.cmd install
npm.cmd test
npm.cmd run dev
```

6. Revise Reportes y confirme filtros, KPI y detalles.
7. En GitHub Desktop use el resumen:

`V9.2.13 - Reportes gerenciales`

8. Pulse `Commit to main` y luego `Push origin`.

No requiere SQL nuevo en Supabase.
